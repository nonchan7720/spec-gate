# 金額計算仕様

本書は金額計算における丸め・締め処理の仕様を定める。

## 背景

給与・請求いずれも円単位で確定させる必要があるため、計算途中の小数は最終段階で丸める。
丸めの方式は税務上の扱いと合わせる。

## 端数処理

金額の円未満の端数は切り捨てる。四捨五入・切り上げは行わない。

| 入力 | 出力 |
|---|---|
| 1234.56 | 1234 |
| 1234.99 | 1234 |
| 0.01 | 0 |

## マイナス金額

計算結果がマイナスになった場合は 0 とする。マイナスの金額を出力してはならない。

## 月末処理

月次の締め処理は月末日に実行する。
月末日が休日の場合でも前倒しはしない。
