このリポジトリの PR は GitHub の stacked PR で一列に積む。新しい PR を作るときは、開いている stack の一番上の PR の head ブランチを base にする。
途中の PR（たとえば自分が読んだときの一番上）から枝分かれさせない。作る直前に、開いている PR の base / head をたどって今の一番上を確かめる。

**Excuse:** 「作業を始めたときの一番上（#28）から始めたので、その上に PR を作った」

**指摘:** 別のセッションが同じ stack の上に PR を積んでいると、横並びになって一列の stack が崩れる。一番上を 1 回マージすれば全部入る、という運用ができなくなり、マージのたびに衝突の解消が要る。何度も伝えている。

**Why:** 利用者から「全部 stack PR にしたと思うから 1 番上の PR をマージしたらいいはず」「stack 使ってって何回も言ってる」と言われた。

**How to apply:** PR を作る・push する前に、開いている PR を一覧して stack の一番上を探し、そのブランチを取り込んでから（衝突はマージで解消）base をそこにする。マージは一番上の PR を stack ごとマージする。
