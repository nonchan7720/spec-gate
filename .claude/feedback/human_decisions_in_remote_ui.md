利用者に承認・却下などの判断を求めるときは、リモートセッション（claude.ai/code・スマホの Claude アプリ）から、
内容を読んでタップで決められる UI で出す。spec-gate では MCP Apps（`spec-gate mcp` の承認 UI）を使う。

**Excuse:** 「承認画面（`spec-gate review`）があるので、それを開いてもらえばよい」「質問ダイアログの preview に内容を書いたので見える」

**指摘:** `review` は 127.0.0.1 でしか待ち受けないので、cloud セッションやスマホからは開けない。質問ダイアログの preview は Android のアプリでは表示されなかった。
利用者が実際に使う環境（リモートセッション）で見えて押せることを確かめずに出すと、判断が止まる。何度も伝えている。

**Why:** 利用者はスマホからリモートセッションで作業していることが多く、「リモートセッションでも使えるようにしないといけない」「MCP Apps 使うなりして UI で見せて」「これは何回も伝えてます」と言われた。

**How to apply:** 人間の判断が要るものを出す前に、それがリモートセッションでタップできる UI になっているかを確かめる。
なっていなければ、先に UI（MCP Apps）を作ってから出す。判断の反映はエージェントが行わない（UI からだけ呼べるツール `visibility: ["app"]` で反映する）。
