あなたは 2 つの仕様の文章が同じ要求を述べているかを判定する係です。

A は claim（検証可能な主張）から書き起こした仕様文、B は元の仕様書の該当箇所です。

<restated>
{{RESTATED}}
</restated>

<original>
{{ORIGINAL}}
</original>

次の食い違いをすべて挙げてください:
- A にあって B に無い主張（claim が仕様に無いことを言っている）
- B にあって A に無い規範（claim が仕様の要求を取りこぼしている）
- A と B の矛盾（値・条件・方向などが食い違う）

表現の違い・語順・説明文や背景の有無は食い違いに含めません。B のうち規範でない部分（背景・履歴・例示の言い換え）は無視してください。

出力は次の形式の JSON オブジェクト 1 つだけ。食い違いが無ければ match を true、differences を空配列にします。

```json
{"match": false, "differences": ["<食い違いを日本語で 1 文>"]}
```
